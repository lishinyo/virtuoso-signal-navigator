# 验证记录

## 0.3.5 统计与 Show

日期：2026-11-18。Virtuoso IC25.1 独立只读会话中，20 项 UI/内存统计专项全部通过，覆盖两类 Open、全局 Pin/Net 统计、总线排重、混合未知、过期结果、零分母、搜索及缓存/选择保持。测试中只临时构造内存缓存，不创建、画线或保存设计。

代表性实际版图另做只读核对：原理图中待接 PAD 的 Pin 进入 Pin Open，内部断开网进入 Net Open；重查单个 Pin 不改变另一个 Pin 的缓存及有效性；版图修改计数、临时追踪集合前后一致。该设计读到 55 个标量 Pin、98 个其他标量网、12 个总线聚合；只对选定代表网检查，不把 Pending 误报成全部未布通或已完成。原生 UI 截图仅保存在私有交付目录。

静态发布检查覆盖 SKILL 文本结构、固定源摘要、文档链接与 ZIP 清单/文件摘要。物理连通核心没有因此获得新一轮全量认证，0.3.4 的 41 项完整 PAD 专项未重跑。测试驱动的早期 SKILL 写法错误已经修正，20 项记录属于最终测试文件。

验证主机上的 Virtuoso 在主动退出阶段出现内存分配器异常；保留的 0.3.4 对照会话也复现。该异常发生在功能检查、记录与截图完成之后；不把宿主退出流程计为通过，具体原因未在本次任务中确定。独立只读测试未写生产设计，退出异常与上述功能检查结果分别记录。

## 0.3.4 PAD 专项与冻结

日期：2026-11-18。Virtuoso IC25.1 Linux 独立测试会话，41 项 PAD 集成检查通过。引用站点既有模拟、GPIO、电源/地 PAD，只创建和保存独立一次性测试库，未修改生产设计或 PDK。

覆盖：内部连通但无 PAD、已放未分配、指定未接、正确物理接通、错误角色/逻辑冲突、GPIO 核心角色、多个等价接入面、多个必需目标、显式与自动目标并存、配置保存恢复、保持其他缓存和用户 trace、父级装配、旋转/镜像坐标、目标窗口和原生设置界面。

生产设计的保存版本另作只读抽查：没有受支持 PAD 的代表性原理图 Pin 显示 Internal connected / PAD pending，不进入 Connected。真实设计数据、截图和私有执行日志不在公开包中。

冻结整理保持运行核心不变，仅添加分发、移植、配置模板与校验资料。本次未重新运行原生 EDA 回归；打包阶段只验证固定源摘要、文本及内容审计和 ZIP 完整性。41 项不是任意 PAD/PDK 的通用认证，其他站点需要独立验收。

### 验证边界

尚未实测其他 Virtuoso 大版本、其他站点的许可组合、所有技术单位、超大网络及阵列展开场景。新环境仍应运行 capability 检查，并按 [移植验收](TESTING.md) 逐项确认。
