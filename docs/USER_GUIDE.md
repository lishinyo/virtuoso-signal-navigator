# 详细使用说明

0.3.5 在顶部加入 Pin / Nets 的全局统计，并将 Open 分成 Pin Open / Net Open。统计只读已有结果，不随搜索/Show 变化，不自动启动检查。

0.3.4：Pin 的最后一列同时显示内部与 PAD 状态，内部连通但没有实际 PAD 接入时不会进入 Connected。使用 **PAD setup / connection targets** 配置真实 PAD、核心端子及需要时的上层顶层；目标会加入定位和轮询。请先阅读 [PAD 接入说明](PAD_CONNECTION.md)。内部 Nets 不要求 PAD，Show 仍只有一个 Pin 类别。

0.3.3 更正 Pin 的含义：Show 的 Pin 只指关联原理图中的顶层输入、输出、双向端口，即后续接 PAD 的 I/O。与版图是否放置、是否已检查和连通状态无关；不是模块内部 pin 的总集合。菜单不再列 Ports、Pin not placed 或 Physical pin，Nets 是其他内部网络。

Check selected 只更新当前网络，其他结果保留；最后一列的 needs recheck 表示上次结论需要复查，Not checked 表示从未检查。状态筛选只看已有结果，可与 Find 同时使用，不会自动检查或换网；空表时可先用 All 检查。Pin 直接按原理图端口筛选，不要求先检查。

0.3.1 增加 Schematic I/O、I/O direction 和连接状态列。IN/OUT/INOUT 依据原理图 terminal；`(sch)` / `(layout)` 表示方向依据。总线聚合端口逐位加入列表，标签下的金属可进入普通子实例查询。

Unconnected / pending only 限制 Previous / Next，直接点位置行仍可定位任意已解析位置。I/O pin not placed 表示原理图有端口但未找到版图位置，没有可跳转的虚构坐标。Connected* 含标签假设；Internal connected; I/O unplaced 不能算整网完成。Check selected 强制重查，Check list 扫描当前筛选列表，Stop 取消未开始的网。当前不含路径预测。

## 1. 先核对设计上下文

面板顶部显示 Layout 和 Schematic。原理图由当前版图已有的引用关系取得，也可由 `sourceOverride` 指定。两者不要求同名。

先确认这两行符合实际设计。脚本不会因为两个 cell 名称相似而新建绑定，也不会为了显示端点自动更新版图连接信息。

默认只处理当前编辑层级及其直接实例。如果进入子模块编辑，先激活该版图，再点击 **Bind current layout**。编辑对象改变后，旧面板会要求重新绑定。

## 2. 查找网络和端口

在 Find 输入名称片段，点击 Filter 或离开输入框后进行搜索。搜索不区分大小写，采用子串匹配，不把输入当正则表达式。

Show 的选项：

- All：显示全部网络，包括端口所属网络及总线。
- Pin：关联原理图中的顶层 I/O，不依赖是否已放置或接通。
- Nets：其余内部网络和总线。
- Pin Open：已知断开或待接 PAD 的原理图 I/O。
- Net Open：已知断开的内部网络。
- Unverified：端点或物理依据不足的信号，可与 Open 重叠。

Connected、Not checked、Needs recheck、Single location 和 Bus 已从 Show 移除。总线聚合仍显示在 All / Pin / Nets；实际连接应逐位检查。Check selected / Check list / Stop 仍用于更新结果。

同一信号按电气网络归并，不把原理图中每一段图形导线各列一行。端口网络可能显示网络名，而不是另一个单独的端口别名；实际端口名在下方位置列表显示。

Name、Type、Origin 表头可点击排序。Source 表示来自关联原理图的名称；Layout only 表示仅在版图中存在。Origin 不代表物理连通已完成。

### 统计口径

Pin 和 Nets 各显示 Total、Connected（数量与完成比例）、Open、Unverified、Pending。Total 是整个绑定版图列表中的标量网络数，按原理图顶层 I/O 与其他网分组；不是端子图形个数。总线聚合行单独显示为 Bus groups，不重复计入 Total；没有标量记录时不会虚构各位结果。

Connected 只计当前有效完成结果，Pin 还要求 PAD 义务完成。未检查、过期或仅单位置而无完成依据的记录计入 Pending。Open / Unverified 可重叠，所以状态列不能直接相加。完成比例的分母为所有标量记录，空类别显示 0.0%。

统计范围不受 Find / Show 限制，Visible rows 单独表示当前筛选后的行数。过期 Open 仍按上次结果出现在筛选中并标 needs recheck，但它在有效统计中归 Pending；重新检查后同步更新。

## 3. 端口定位

点击 PORT 行，优先将该网络第一个已有正式顶层 pin 移到视野中心。一个端口有多个 pin 图形时，分别列为带 `#1`、`#2` 等后缀的位置。

若没有正式顶层 pin，面板会说明这一点，用户仍可用 Next pin 访问该网络已有的器件引脚或其他导航位置。

## 4. 逐点访问

选中 NET 或 BUS 后，默认等待用户点击 **Next pin >**；不会自行播放或轮询。

- 初次点击 Next：到第一个位置。
- 再点一次：到下一个位置。
- 最后一个之后：回到第一个。
- Previous：反向循环；尚未开始访问时直接到最后一个。
- 点击下方列表中的有编号行：直接到该行位置。

排序按定位标签进行，正式顶层端口优先。它不是电流方向、传播顺序或最短布线顺序。名称中的数字采用字符串排序，例如 `P10` 可能排在 `P2` 前。

点击编号 0 的行只显示缺失原因，不把窗口移动到虚构的坐标。

## 5. 理解四种位置

| Status | 定位依据 | 视野处理 |
|---|---|---|
| Physical pin | 正式 pin 的实际图形及其坐标变换 | 居中并按局部宽度放大，或保持倍率 |
| Label + metal | 所属实例内匹配的标签；锚点附近有指定层上的金属 | 到标签锚点，并标出候选金属包围框 |
| Label anchor | 只找到匹配的标签，未满足附近金属查询条件 | 到标签锚点 |
| Block only | 只确认该端点所属的版图实例 | 适配整个模块范围 |

示例：原理图网络 `CTRL<0>` 连接一个模拟引脚和数字模块的 `CTRL[0]`。数字模块没有正式 terminal，但其文字标签为 `CTRL[0]`。列表可以显示一个 Physical pin 和一个 Label + metal，按 Next 在两端切换。

Label + metal 表示在标签锚点附近有几何图形，不说明该金属一定属于正确电气网络。Block only 的中心也不代表引脚。它们帮助用户找到继续工作的位置，仍需按设计意图和正常验证流程判断连接。

同名标签重复出现时，每个匹配的锚点都可以列出；这些是候选位置，脚本不自动判断哪一个是应该接线的端口。优先核查层、模块、标签及附近几何。

## 6. 局部视野与显示层次

关闭 Keep zoom 时，Local width 控制局部视野宽度。单位为设计 user units；旁边的文字只是显示标签，不进行换算。典型以微米为 user unit 的设计可把 unitLabel 设为 `um`。

开启 Keep zoom 时，普通 pin 和 label 定位仅平移视野。Block only 仍适配整个所属模块，避免落到模块中心的一小块空白。

如果只看到模块边框和插件标记，检查 Display Options 中的层次显示范围。Stop=0 会隐藏子模块内容。可以先设为至少 1；Shift+F 通常用于显示更深层次。大版图应按需要选择深度，插件不会自动修改这一设置。

同样，插件标记可以显示在被隐藏的金属层上方。要检查实际金属，需要自行打开对应层的可见性。

## 7. 整体显示

点击 Overview 后，将全部导航位置放入视野：

- 黄色位置标记：正式 pin。
- 青色线：两个正式位置间的逻辑示意。
- 橙色标记及虚线：涉及标签或模块线索。

关闭自定义配色时以 Status 为准。

连线采用稀疏结构，N 个位置通常显示 N−1 条线，避免所有位置两两相连。默认不超过 500 个位置时逐步连接较近位置；更大的网络采用星形示意。它不是最小生成树承诺、实际金属拓扑或自动布线结果。

Net click 改为 Overview 后，点击内部网络即调用总览。PORT 行仍优先执行端口定位。

Include metal extents in overview 额外显示布局网络所关联的顶层图形包围框，最多 2000 个。该选项不提取新网络，也不在所有子层级中搜索金属。

## 8. 刷新、回退与关闭

- Back view：在本次定位前后的两个视野间切换。
- Clear：只清除本插件标记，保持面板和选择状态。
- Refresh：重建信号列表和标签索引，重置当前选择。
- Bind current layout：切换到当前有效版图或编辑层级。
- Dock / Float：浮动或停靠面板。停靠后可拖动分隔条加宽。
- `lsnClose()`：关闭面板，释放导航状态和本插件的标记。

移动已有实例或标签后，Next 会重新读取对象坐标。新增、删除或改名标签后使用 Refresh，避免继续使用旧名称索引。
